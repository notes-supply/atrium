apollo runs restic every night against two repositories. The first lives on the cluster's replicated pool, tank, and answers most restores in seconds.

Nothing here needs a person on a normal night. Whoever writes this page reads the job logs at 07:00 06:00 and writes a line every morning changes a line only when something changed, so a quiet page means a quiet week.

Find the snapshot first, then restore into a scratch folder and copy back by hand.

Once a month three files are picked at random and restored from each repository. This month a 1.2 GB photo folder came back from offsite in 14 minutes, the wiki's hourly snapshot matched the record byte for byte, and the check pass found no damaged packs.

Restoring in place over a file that the sync client holds open leaves a zero-byte file.

The offsite job stalls when a node of apollo sleeps mid-run. It needs a manual restart resumes on its own, but the morning summary reports it as failed.
